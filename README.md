# CityMETER: Office

**สำนักงานกระจุกอยู่ตรงไหน ค่าเช่าที่ประกาศเท่าไร และใกล้รถไฟฟ้าแค่ไหน** — เดโมแผนที่ 3 มิติของสำนักงานทั่วประเทศไทย ที่อ่านรายการสำนักงานเป็นยอดต่อเขต/อำเภอ อ่านค่ากลางของค่าเช่าเริ่มต้นที่ประกาศต่อพื้นที่ พร้อมระยะถึงสถานีรถไฟฟ้า องค์กรที่ผูกกับสำนักงาน ค่าเช่ารอบ ๆ แต่ละอาคาร และที่มาของทุกตัวเลข

- เว็บ: https://montri-th.github.io/office/
- ระบบจริงของ CityMETER: https://landometer.com/v3/citymeter?d=office
- รุ่น 0.1.0 · 5 พฤศจิกายน 2569 · ชีตวิจัยตรวจแหล่ง 24 ต.ค.–2 พ.ย. 2569 (ผูกอาคาร 2 พ.ย.) · ราคาประกาศเดือน พ.ค.–ต.ค. 2569 · ขอบเขต production อ่าน 1 พฤศจิกายน 2569

ข้อค้นพบแรก (snapshot ปัจจุบัน ไม่กรอง): **47% ของสำนักงานในกรุงเทพมหานคร (202 จาก 429 แห่ง) อยู่ใน 4 เขต — บางรัก ห้วยขวาง วัฒนา ปทุมวัน** (วัฒนากับปทุมวันเท่ากันที่ 46 แห่ง จึงอยู่ด้วยกัน) · ใกล้รถไฟฟ้า ≤ 500 ม.: 4 เขตนี้ 71% (136/191 แห่งที่มีพิกัด) เขตอื่น 53% (93/175) · อันดับ 1 นอกกรุงเทพฯ คืออำเภอเมืองเชียงใหม่ 15 แห่ง

บนมาตรวัดค่าเช่า: **ค่ากลางของค่าเช่าเริ่มต้นที่ประกาศสูงสุดในกรุงเทพฯ คือปทุมวัน ฿983/ตร.ม./เดือน (26 ราคา)** ตามด้วยคลองเตย ฿713 (24) และวัฒนา ฿665 (29) เทียบทั้งกรุงเทพฯ ฿610 (250 ราคา) · ในกรุงเทพฯ ราคาประกาศของสำนักงานที่ห่างสถานีรถไฟฟ้า ≤ 500 ม. มีค่ากลาง ฿743 (166 ราคา) ที่ไกลกว่านั้น ฿500 (80 ราคา)

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/map-style.js` กราฟไม่ใช้ไลบรารีภายนอก ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ โค้ดฐานมาจาก CityMETER · Hotel 0.3.6 (montri-th/hotel @177e592)

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรกแบบ 3 มิติ:** โฟกัสเขต/อำเภอที่มีสำนักงานมากที่สุดของจังหวัดที่มีสำนักงานระดับเขตมากที่สุด บอกสัดส่วน ตัวตั้ง ตัวหาร สัดส่วนใกล้รถไฟฟ้าเทียบส่วนอื่นของจังหวัด และพื้นที่ที่มากที่สุดนอกจังหวัด — ไม่ตัดผ่านค่าที่เท่ากัน (ค่าที่เท่ากันเข้าโฟกัสด้วยเมื่อรวมแล้วไม่เกิน 4 พื้นที่) และไม่โฟกัสทุกเขตของจังหวัด
- **สำนักงาน | ค่าเช่า:** สลับมาตรวัดในคำอธิบายแผนที่ แผนที่ ป้าย ข้อค้นพบ อันดับ และกราฟเขต/อำเภอเปลี่ยนพร้อมกัน (สเกล `count` สำหรับแห่ง และ `price` สำหรับค่าเช่า ครบ 41 ระดับของ LDS) ค่าเช่าของพื้นที่คือค่ากลางของราคาประกาศที่มีเดือนกำกับ ใช้เมื่อมีอย่างน้อย 5 ราคา พื้นที่ที่มีน้อยกว่าเป็นลายทแยงและแผงบอกจำนวนราคาที่มี
- **รูปแบบสำนักงาน:** สำนักงานให้เช่า · พื้นที่ทำงานแบบบริการ · สำนักงานขององค์กร · ใช้เองและให้เช่า · ยังไม่ระบุรูปแบบ — สีและรูปทรงตาม LDS series กรองได้ทุกจุด
- **ที่มาของรายการ:** ยืนยันจากแหล่งหลัก · ข้อมูลเดิมจาก CityMETER production · รอตรวจหลักฐาน — เป็นตัวกรองและแถบในแผงภาพรวม
- **สถานีรถไฟฟ้า (CityMETER Transit):** วงกลมเล็กบนแผนที่ กดเพื่อดูสำนักงานในรัศมีระยะตรง 500 ม. พร้อมวงรัศมีบนแผนที่ และลิงก์ไปสถานีเดียวกันใน CityMETER Transit
- **ชื่อสำนักงานกลางจอ:** ตั้งแต่ระดับไซต์ ชื่อสั้นของสำนักงานในอาคารสูงและค่าเช่าที่ประกาศสูงก่อน ไม่เกิน 9 ป้าย (มือถือ 5) พร้อมค่าเช่าเริ่มต้นที่ประกาศ ชี้แล้วเห็นการ์ดไอคอน: รูปแบบ ชั้น ค่าเช่า องค์กร
- **สำนักงานหนึ่งแห่ง:** กดสำนักงานที่มีพิกัด แผนที่เปลี่ยนเป็น 3 มิติและเปิดมุมมองอาคาร 2-point perspective — อาคารที่หมุดอยู่ในขอบ หรืออาคารที่ใกล้หมุดที่สุดภายใน 300 ม. (ไม่มีก็ขยายเป็น 800 ม.) · ค่าเช่าที่ประกาศพร้อมเดือน จำนวนชั้น พื้นที่ อัตราการเช่าตามรายงานเจ้าของ (บางอาคาร) องค์กรและบทบาท สถานีที่ใกล้ที่สุด · **ค่าเช่ารอบ ๆ** (สำนักงานที่มีราคาประกาศในระยะตรง ≤ 1 กม. เรียงใกล้ก่อน พร้อมค่ากลางรอบอาคาร)
- **องค์กร:** กรองตามองค์กรเพื่อดูสำนักงานทั้งหมดขององค์กร บทบาทตามชีต (ใช้เป็นสำนักงาน ผู้ให้บริการพื้นที่ทำงาน แบรนด์ให้เช่า ฯลฯ) จังหวัด และสัดส่วนใกล้รถไฟฟ้า กราฟ “องค์กร” จัดอันดับองค์กรตามจำนวนสำนักงาน
- **อาคารรายพื้นที่และภูมิประเทศ:** ใช้กติกาเดียวกับ Hotel — อาคาร CityMETER Building V4 ในพื้นที่ที่มีอาคารมากกว่า OSM ตั้งแต่ 15% ไม่เช่นนั้นใช้ OSM และภูมิประเทศ 3 มิติในพื้นที่เนินเขา
- **ภาษา:** สั้น ใช้ไอคอนและกราฟแท่งเล็กแทนประโยค ไม่มีคำเตือนบนหน้าจอ ทุกหน้าจบด้วยบรรทัดที่มาและลิงก์ “วิธีนับ”
- **มือถือ:** ข้อค้นพบกับคำอธิบายแผนที่รวมเป็นแถบเดียวด้านล่าง ใช้สองนิ้วซูม แผงข้อมูลเปิดตรงสำนักงานหรือพื้นที่ที่เลือก
- **ถามต่อใน Google:** ทุกมุมมองมีปุ่มถาม Google AI ด้วยคำถามที่ตรงกับสิ่งที่กำลังดู พร้อม Google Maps และ Street View เมื่อมีพิกัด · คำตอบของ Google ไม่ถูกนำมาเป็นข้อมูลในหน้านี้
- **เส้นทาง:** ประเทศไทย › จังหวัด › เขต/อำเภอ ใช้รหัสเดียวกับ CityMETER production และเปิดพื้นที่เดียวกันในระบบจริงได้ (`?d=office`)
- **ลิงก์ตรง:** `?metric=rent` · `?area=1007` · `?areas=1004,1017,1039` · `?areas=all` · `?province=CMI` · `?group=workspace` · `?ev=confirmed` · `?size=f4` · `?org=<id>` · `?office=<Office ID>` · `?station=<id>` · `?view=orgs` · `?view3d=0`

## ข้อมูล

- `data/offices.json` — 608 รายการสำนักงาน (Office ID) จากชีตวิจัย ไม่รวมรายการอ้างอิงรวม 4 รายการที่ชีตกำหนดให้นับผ่านอาคารย่อย (ไม่เผยแพร่ชีตหรือไฟล์ที่อ่านมา เก็บเฉพาะ SHA-256 ของแต่ละแท็บ) — `scripts/build-data.py`
- `data/area-index.json`, `data/frames/{CODE}.json`, `data/provinces.geojson` — เขต/อำเภอและจังหวัดของ CityMETER production — `scripts/build-boundaries.py`
- `data/boundary-receipts.json` — ใบรับของทุก response จาก production base info
- `data/building-units/` — แหล่งอาคารราย อปท./เขต ตามเกณฑ์ 15% (ชุดเดียวกับ Hotel 0.3.6; หน่วยที่ไม่มีในไฟล์ใช้ OSM)
- วิธีทั้งหมด ข้อจำกัด และงานวิจัยที่ต้องตามต่อ: `DATA_METHOD.md` · กลยุทธ์ผลิตภัณฑ์: `PRODUCT_STATEMENT.md` · สำหรับนักพัฒนา: `handoff/START_HERE.md` · สำหรับ agent: `llms.txt`
